Project Overview

CUbe of Steel is a action puzzle game, where the user must reach the end of the level while dodging obstacles and unlocking doors.

The content of the rooms gets iterated throughout the game, developing the mechaincs present.

An in game text provides commentary and hints throughout the game.

Features and Tools used

Key Features

  • A complete game with a defined start and end
  • Mechanics are developed and iterated upon throught gameplay
  • Grading system to clearly show the player's performance at the end of the game

Technologies Used

  • Developed using Game Maker
  • Sprites created using Game Maker sprite tools
  • Audio from retro games

Development Process

The game was developed during 6th Form, based on a project that was being worken on in the Computer Science lessons. The base game reminded me of old flash games in its gameplay, and I sought to emulate the gameplay seen in World's Hardest Game while developing this game.

Reflections

This game was fun to make, as each level was self contained, thus making content for this game was as simple as adding more left after the last. The final sequence of the game was somewhat rushed, and a slightly more smooth transition to the ending screen could be possible.
