Project Overview

Speck is a short adventure game, where the player is tasked with deciding how to spend their limited lifespan.

There are 6 different planets to visit, each giving a task that represents a potential goal in the player's life.

There is a 5 minute timer present, and the player will die once the time is up. If the player is hit twice during gameplay, the game is finished immediately.

The intent is to only play this game once.

Features and Tools used

Key Features

  • Complex dialogue system with pictures and portraits for the various characters.
  • Dynamic map system to allow players to quickly determine their position.
  • Functioning quest system that tracks the player's progress, and updates the game state accordingly
  • Responsive input system which makes controlling the player character appealing.

Technologies Used

  • Developed using GameMaker
  • Graphics created using Aseprite
  • Audio from Pixabay

Development Process

This was developed as a final year project for the Interactive Media course, with the aim of investigating a new way to depict death in video games that is both meaningful and approachable.
The timer system was implemented to ensure that "Death" or game over will be inevitable, along with the intention of only allowing the players to play the game once.
To make depicting the death of the player character more approachable, the player character became a 'spark' that will 'fizzle out'.
The space setting was chosen to explain the top down movement of this game, as well as allowing each of the potential paths to be split into different planets.
The 2 hit point present for the player is to allow the player to realise that the next hit will be fatal, making them more wary during gameplay.

Reflections

This project was successful in some of its goals, mainly in allowing the player to think about mortality in a more approachable setting.
To improve, I believe the game length needs to be increased, and the game should incorporate a more through method of preventing the player from playing the game again.
